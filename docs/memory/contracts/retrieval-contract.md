# Retrieval request and response

## Request

```json
{
  "tenant_id": "example",
  "user_id": "alice",
  "query_text": "What database does Atlas use?",
  "query_vector": [1.0, 0.0, 0.0],
  "entities": ["Atlas"],
  "token_budget": 1800,
  "privacy_scope": ["private"],
  "top_k_vector": 12,
  "max_graph_hops": 2
}
```

The vector above is illustrative for a three-dimensional configuration, not valid against the example production dimension of 1536. Host embeddings and extracted entities are inputs, not generated by Nextral. Optional fields include `session_id`, `intent_topic`, `lane`, `policy_version`, `trace_id`, and `scoring_weights`.

## Response shape

The response includes `retrieval_id`, `trace_id`, `status` (`ok`, `degraded`, `error`), effective `lane`/`policy_version`, `quality_score`, `severity`, `decision_action`, optional `rollback_id`, `telemetry` and `items`.

Each item carries `memory_id`, canonical `content`, `source_path` (`vector`, `graph`, `both`), `retrieval_score`, `score_breakdown` (`semantic_similarity`, `recency`, `importance`, `access`), and `token_estimate`. Counts and stage timings are nested under `telemetry`, not flattened top-level fields. Telemetry also carries token utilization, dedupe ratio and degraded reasons.

A quality/severity field is a runtime decision signal, not an empirical hallucination rate or an evaluation result. Weighted scoring follows configured policy rather than requiring the example's 0.5/0.2/0.2/0.1 weights.

## Execution and freshness

Enabled vector and graph paths run in parallel, deduplicate IDs and hydrate active canonical records in one scoped query before selection. Tenant/user/privacy and lifecycle checks remain authoritative even if external payloads are stale. Access metadata updates atomically without reindexing vectors. One failed enabled path can yield degraded results; all enabled paths failing returns explicit error.

The token budget bounds the estimated memory contribution, not every token in the host model prompt. Reusing a batch-read idempotency key fences a request fingerprint but never returns a persisted raw retrieval body: updates, forget and privacy changes must be observed freshly.
